# CMVS 2007 i386 startup on 2026-11-23

The original Japanese Primitive Link disc directory contains an i386
`cmvs.exe` dated 2007-01-19, `cmvs.cfg`, `data/pack/start.ps2` and ten CPZ3
archives. The original configuration specifies a 1024 × 614 canvas. The
launcher previously rejected the executable before opening the script.

The native [ABI notes](../../crates/crysirror-cmvs/NATIVE_ABI.md) identify the
loader, archive reader and dispatcher. The release macOS player on Apple M4
Max ran 3,600 headless frames with audio disabled and a separate writable
directory. The final frame matched the dialog rendered in an earlier
1,800-frame run. Its active script was `protect.ps2` at offset `0x1f67a`.
The rendered Japanese dialog asks for GAMEDISC and a restart. The host had a
directory copy of the disc and no mounted original optical disc. Title and
story were outside the verified run. The adapter's registration limitations
are recorded in [SATD](../../crates/crysirror-cmvs/SATD.md#satd-cmvs-20070119-profile).

An independent read of the installed script pack checked its index and all
140 member checksums and decoded each PS2A payload. The release integration
test also opened and decoded all 140 scripts through the scoped Rust resource
reader. All 17 VM script regression tests passed. The synthetic shared
reader regression checks index and member corruption and a non-word-aligned
index and payload.
