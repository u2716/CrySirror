# crysirror-unity

Bounded readers for Unity 4.x player data (serialized file format 9 without
type trees), producing engine-owned data: object tables, GameObject/Transform
hierarchies, MonoScript names, Texture2D level 0 (Alpha8, ARGB4444, RGB24,
RGBA32, ARGB32, DXT1, DXT5), Material properties, Font TrueType data, Sprite
rects, uncompressed Mesh vertex/index data, renderer material lists, shader
names, `ResourceManager` paths and `BuildSettings` levels. `managed.rs`
decodes MonoBehaviour fields under a consumer-supplied schema (see
`tools/unity_managed_schema.py`); `gltf.rs` assembles hierarchies into GLB for
the world renderer. No Unity code, scripts or devices are hosted. Other Unity
versions and compressed meshes fail visibly.

## Unity 2020+ data (serialized format 22, UnityFS)

- `bundle.rs`: UnityFS archives (formats 6–8; LZ4/LZ4HC, LZMA and stored
  blocks; block info at the start or end, 16-byte padding). Directory nodes
  are random-access readers that decompress only the touched blocks (a small
  per-bundle cache); stored blocks are read in place.
- `SerializedFile::open` reads format 22 metadata: serialized types with
  script ids and type trees, 64-bit object offsets, script types, externals
  and `[SerializeReference]` reference types.
- `typetree.rs`: blob type trees (local and Unity common strings) and a
  generic decoder to `managed::Fields` (aligned fields, arrays, strings,
  `TypelessData`, PPtrs, `ManagedReferencesRegistry`). A decode must consume
  every byte of the object.
- `TreeRegistry`: trees harvested from bundles of the same player for files
  built without trees (player `level*`/`*.assets`), by class id and by the
  MonoBehaviour script id.
- `managed_gen.rs`: MonoBehaviour trees derived from managed metadata
  (ECMA-335 assemblies through `crysirror-dotnet`; for IL2CPP players the
  metadata-only assemblies regenerated by Cpp2IL with its attribute
  processors) under Unity's serializer rules, for scripts no bundle carries.
- `classes::resource_container_64`: `ResourceManager` with 64-bit path ids.

Owner-corpus evidence (甘夏ろけーしょん, Unity 6000.0.65f1):
`UNITY6_BUNDLES=<game> UNITY6_DATA=<game>/AmanatsuLocation_Data UNITY6_ASSEMBLIES=<cpp2il dummy dir> cargo test --release -p crysirror-unity --test unity6_bundles -- --ignored`.
All 392 `lib/` bundles (358,891 objects) and the Addressables bundles decode
byte-exactly; player files decode through the registry and generated trees
except editor-only assets (`UnityEditor.ShaderGraph.SubGraphAsset`),
MonoBehaviours without a script, `UniversalRenderPipelineGlobalSettings`
and the `globalgamemanagers` settings singletons (no trees; `BuildSettings`
and `ResourceManager` have fixed readers).

## Unity 2020+ assets, scenes and UI

- `unity6.rs`: `Texture2D` (inline or streamed `.resS` data; BCn through
  `crysirror-image`), `Mesh` vertex streams (skin weights, blend shapes,
  sub-meshes), `Sprite` render data including `SpriteAtlas` packing.
- `scene6.rs`: GameObject/Transform/RectTransform hierarchies with every
  decoded component (MonoBehaviours named by their script class);
  `subtree` instantiates one prefab root as its own scene.
- `ugui.rs`: uGUI layout of a `Scene6` into draw items and raycast targets —
  `Canvas`/`CanvasScaler`, RectTransform anchors/pivot/scale, layout groups,
  `LayoutElement`, `ContentSizeFitter`, `Image` (simple, sliced, filled),
  `TextMeshProUGUI` runs, `CanvasGroup` alpha and its `blocksRaycasts` /
  `interactable` inheritance (`ignoreParentGroups`; a group on a root Canvas
  object applies to the whole canvas). Per-node `NodeState` overrides carry
  runtime changes.
- `world6.rs`: 3D content for the world renderer — `Material` +
  shader name → engine material (URP Lit/Simple Lit, Standard, ILLGAMES
  `AL/Map`: base colour/map, cutout/transparent, cull, metallic/smoothness
  and `_MetallicGlossMap` → glTF roughness/metal, `UnpackNormalmapRGorAG`
  normals, occlusion, emission; SpeedTree 8 foliage; unlit; particles and
  NatureManufacture water approximated; Lux FX volumes, skyboxes and
  `Hidden/` shaders skipped), MeshFilter/MeshRenderer hierarchies as GLB
  chunks under the engine's 64 MiB model limit (LOD 0 only, static batches
  from their combined mesh, shared meshes per chunk, renderers grouped by
  material), a prepared-texture budget (`fit_textures` halves the largest
  textures first), `Light` components with culling masks and
  `RenderSettings` ambient/fog; `SkinnedMeshRenderer` as glTF skins
  (`m_Bones` joints, bind poses mirrored `S·M·S`, joints/weights), with
  `Scene6::graft` parts (per-node file keys) and `Scene6::alias_bones`
  name-based rebinding onto another skeleton; a consumer `material_hook`
  (per renderer file) for runtime-composed textures, colours, alpha and
  hiding. Lightmaps, reflection probes, terrain, particle systems, blend
  shapes and shader-graph effects are not converted.
- `msgpack.rs`: bounded MessagePack decoding (MessagePack-CSharp payloads).
- `animator.rs`: Mecanim without Unity — `AnimationClip` muscle clips
  (streamed cubic segments, dense samples, constants) with their generic
  bindings, `AnimatorController` layers, states, exit-time transitions and
  cross-fades, `Animator.Play(state)`; path/attribute CRC-32 resolution onto
  uGUI properties (GameObject active, CanvasGroup alpha, Graphic/TMP colour,
  anchored position, size delta, local scale, fill amount). Parameter
  conditions, blend trees beyond a single motion, root motion and humanoid
  muscles are not evaluated.
- `events.rs`: `UnityEvent` persistent calls (target, method, argument mode)
  for the consumer to invoke.
